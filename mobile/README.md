# Unveil — mobile app (Expo / React Native)

Android + iOS client for the Unveil server in `../server`.

```bash
npm install
EXPO_PUBLIC_API_URL=https://your-server npx expo run:android   # needs Android SDK locally
npx tsc --noEmit && npx expo lint                               # checks
```

The APK is built in CI by `.github/workflows/android-apk.yml` and published as a GitHub Release.
Build-time settings are documented at the top of `app.config.ts`.

Native folders (`android/`, `ios/`) are generated by `npx expo prebuild` — never edit them by hand;
native changes go through `app.config.ts` and `plugins/`.
